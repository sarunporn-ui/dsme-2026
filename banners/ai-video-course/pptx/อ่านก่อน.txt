1 Day AI ตัดคลิป — ไฟล์แบนเนอร์แก้ไขได้ (PowerPoint)

ไฟล์
- 1Day-AI-ตัดคลิป_1x1.pptx   (1080x1080)
- 1Day-AI-ตัดคลิป_4x5.pptx   (1080x1350)
- 1Day-AI-ตัดคลิป_16x9.pptx  (1920x1080)
  แต่ละไฟล์มี 3 สไลด์: A Classic / B Spotlight / C Ticket

ขั้นที่ 1 — ติดตั้งฟอนต์ก่อนเปิดไฟล์ (สำคัญ)
- ดับเบิลคลิกทุกไฟล์ในโฟลเดอร์ fonts > กด Install / ติดตั้ง
- ปิดแล้วเปิด PowerPoint ใหม่
- ถ้าใช้ Canva: อัปโหลดฟอนต์ใน Brand Kit ก่อน แล้วค่อย Import ไฟล์ .pptx

ขั้นที่ 2 — แก้ไข
- ข้อความทุกจุดเป็นกล่องข้อความ คลิกแล้วพิมพ์แก้ได้เลย (1 บรรทัด = 1 กล่อง)
- การ์ด / วงกลมราคา / ตั๋ว / ปุ่ม / รูปคน / โลโก้ เป็นรูปแยกชิ้น ย้ายหรือลบได้
- เปลี่ยนรูปคน: คลิกขวาที่รูป > Change Picture

ขั้นที่ 3 — Export เป็นภาพ
- PowerPoint: File > Export > PNG (เลือกเฉพาะสไลด์ที่ต้องการ)
